 # Network topology diagram

NETWORK: app-network
- mongodb (Database, port 27017)
- mongo-express (Web UI, port 8081, connects to mongodb by service name)
- node-app (Client application, connects to mongodb by service name)

NETWORK: second-net
- secondnet-container

NETWORK: third-net
- thirdnet-container

* Isolation exists between secondnet-container and 
  thirdnet-container (no direct communication)
  
* After running 'docker network connect third-net secondnet-container', 
  communication becomes possible

 # Explanation of different volume types used

 -- Named volumes - production databases (e.g., MongoDB data files). 
    Safe when containers are deleted.

 -- Bind mounts - local development. Real-time code 
    synchronization between host editor and container.
 
 -- Tmpfs mounts - high-performance temporary caching, logging sensitive credentials.
